# Swiggy 2025 Power BI Dashboard (3 Pages)

This is my Power BI portfolio project built using a Swiggy-style food delivery dataset for the year 2025.
The report is designed in a dark theme and includes 3 interactive pages with KPIs, delivery performance and loss analysis.

## Project Highlights
 50,000 orders (full year 2025)  
 Excel feature engineering (new columns created manually)  
 Power BI Dashboard (3 pages)  
 DAX measures for KPIs & analysis  
 Filters/Slicers + Page Navigation buttons  

## Pages Included (Power BI)
## Page 1: Executive Summary
- Total Orders, Revenue, Profit/Net Value
- On-Time Delivery %
- Revenue trend by Month
- Top Cities by Revenue
- Cuisine share
- Order Status breakdown
- Top Restaurants

## Page 2: Delivery & SLA Performance
- Avg Delivery Time, Avg Delay
- On-Time vs Late Orders
- SLA Bucket analysis
- Delivery time trend (Month wise)
- Delivery performance by City
- Delay analysis by Day Part

## Page 3: Cancellation & Loss Analysis
- Cancelled Orders, Refunded Orders
- Cancellation %
- Cancellation Loss, Refund Loss, Total Loss
- Loss trend by Month
- City-wise cancellations
- Restaurants causing high loss

## Excel Columns Created
I created additional columns in Excel for analysis such as:
- Month Name, Quarter, YearMonth
- Weekday, Hour, Day Part
- Delay Min, On Time Flag
- SLA Bucket
- High Value Order flag
- Delivered / Cancelled / Refunded flags

## Assumptions (For Practice)
This project is for learning and portfolio purposes, so profit/revenue is calculated using assumptions:
- Platform Fee assumed as 4% of Order Value
- Food Cost assumed as 52% of Order Value
- Delivery Ops Cost assumed using distance based rule

- Microsoft Excel
- Power BI Desktop
- DAX
